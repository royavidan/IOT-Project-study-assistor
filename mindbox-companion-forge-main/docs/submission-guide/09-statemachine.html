9. מכונת המצבים וזרימת הנתונים

המכשיר בנוי כמכונת מצבים (FSM) של 16 מצבים. הלב הוא מחזור חיי הסשן; סביבו מצבים לצימוד, שחזור, אג'נדה, שיעורי בית, שגיאה ודיאגנוסטיקה. כל tick קורא קלט → מריץ את ה-FSM → מצייר → מפרסם טלמטריה.

9.1 המצבים

16 המצבים (types.h): ST_BOOTING, ST_IDLE, ST_RUNNING, ST_PAUSED, ST_COMPLETE, ST_LOGGING, ST_ERROR, ST_PAIRING, ST_DIAG, ST_RESUME, ST_CYCLE_OFFER, ST_WIFI_SETUP, ST_AGENDA, ST_AUTOSTART, ST_MESSAGE, ST_HOMEWORK. הדיספאצ'ר הוא ה-switch הגדול ב-StateMachine::tick().

9.2 מחזור חיי סשן

Boot: טעינת DeviceConfig מ-NVS; אם קיים checkpoint ⇒ ST_RESUME, אחרת ⇒ ST_IDLE (offline-first: תמיד עולה לתפריט שמיש). Start: startSessionMode(MODE_WORK) ⇒ Session::start() חומש את הטיימר של 10ms, שומר checkpoint, מנגן צליל, ונכנס ל-ST_RUNNING. Running: מעקב הפרעות סביבתיות, coaching מסתגל, טיפול בנוכחות/היעדרות (עם auto-pause אופציונלי), ורישום דגימות. בסיום ⇒ onTimerComplete() ⇒ שמירה + לוגיקת מחזור פומודורו ⇒ ST_COMPLETE ⇒ ST_IDLE או ST_HOMEWORK. 9.3 מה נאסף ונשלח

בתוך סשן נרשמת דגימה Sample{ t, fle, noise, tempC, lightLux } כל SAMPLE_PERIOD_MS (WORK=60s, coaching=30s, break=120s; מקס' 120 דגימות). ה-Focus Load Estimate (FLE) הוא שקלול של התקדמות, רעש, שונות-אור ונוכחות. במקביל, snapshot חי נדחף למשימת הרשת ~1Hz ובכל מעבר-מצב (publishTelemetry() → TelemetrySnap): מצב, mode, זמן נותר, FLE, סוללה, JSON תקינות-חיישנים, ואופציונלית טמפ'/לחות/אור/רעש. 9.4 צימוד ופקודות מרחוק

צימוד: enterPairing() מייצר קוד 6-ספרתי (esp_random()%1000000), שולח POST /ingest/pairing, ומצב ST_PAIRING מושך config כל 3s עד ש-paired:true. Downlink: syncDownlink() מפרסר JOSN שטוח ומחיל הגדרות (ערכת צבעים, זמני פומודורו לפי timingRev, מצב מבחן/DND, סטריק, שיעורי בית) ופקודות מרחוק (CMD_START/END/RING/MESSAGE). Sign-out: signOutAccount() שולח /ingest/unpair + guard של 90s נגד paired:true ישן שבדרך. StateMachine.cpp L301-334, L657-696 · Cloud.cpp L538-663

איך מוכיחים את זרימת הנתונים: מסיימים סשן ⇒ בעמוד /session/$id באתר מופיעים גרפי ה-FLE והרעש דקה-בדקה + ספירת ההפרעות — הנתונים שנאספו הרגע. פקודה מרחוק ("Ring") מדגימה את הכיוון ההפוך (פרק 10).
