12. תסריט ההדגמה (30 דקות)

עיקרון המנחה: "תדאגו שיש דרך להציג ולוודא כל טענה שאתם טוענים." הפרק הזה נותן תסריט מלא של 30 דקות שבו כל טענה מלווה בהוכחה חיה, עם הפלט המדויק שצריך להצביע עליו, וגיבוי בסימולטור אם החומרה מסרבת לשתף פעולה.

12.1 צ'ק-ליסט לפני הדמו

#מה לוודאלמה
1ספק 5V חזק (מטען קיר/פאוורבנק טוב, לא רק USB של לפטופ)המיקרופון+ToF מעלים זרם boot; ספק חלש ⇒ brownout ואתחול-לולאה (פרק 8)
2רשת Wi-Fi 2.4GHz זמינה (לא 5GHz בלבד)ה-ESP32-S3 תומך רק ב-2.4GHz
3dev server רץ (bun run dev → http://localhost:8080) או האתר המפורסם, עם DEVICE_INGEST_SECRET ומפתחות Supabase תואמים למכשיראחרת המכשיר יקבל 401 מול הענן
4/device פתוח על מסך גדול; המכשיר מצומד לחשבוןנקודת ההוכחה החזותית המרכזית
5Serial monitor פתוח @115200self-test + מוניטור m
6המגע מכויל (אם לא — החזקה ארוכה על BOOT)ניווט חלק בזמן הדמו

12.2 טבלת טענה → הוכחה (עם הפלט המדויק)

#הטענההפעולה החיההפלט המדויק להצביע עליו
1המכשיר מדווח לענן כל 30sלפתוח /device ולחכותנקודת Online ירוקה; "Room right now" מתעדכן. כיבוי ⇒ "Last seen" תוך 90s

4טמפ'/לחות נמדדותנשיפה חמה על ה-DHT11הטמפ' עולה ב-Serial/Diag תוך שניות, ואז ב-"Room right now"
5חיישן אור + בהירות אוטומטיתלכסות את החיישן בידה-lux צונח ב-Diag; המסך מתעמעם פיזית
6הפרעות מגיעות לענן דגימה-בדגימהסשן קצר עם רעש מכוון + התרחקות/session/$id: גרף FLE+רעש לאורך הדקות + ספירת הפרעות
7האתר שולט במכשיר מרחוק"Ring my device" מ-/deviceהמכשיר מצלצל ≤60s; באתר Queued→Sent→Done
8שינוי הגדרה מגיע למכשירלהחליף ערכת צבעים ב-Settingsצבעי המסך מתחלפים ≤60s
9שיתוף IO21 (אנקודר+טמפ') עובדלסובב אנקודר, ללחוץ ציר, לנשוף על DHTהסמן זז (IO2/14) · בחירה (IO21) · טמפ' עולה (IO21) — מאותו רכיב, בלי התנגשות
10offline מלא + סנכרוןלכבות ראוטר, סשן שלם, להדליקSerial q: סשן בתור ⇒ מופיע באתר עם זמנים נכונים (NTP)
11תקלת חיישן מדווחת, לא נבלעתלנתק DHT (או --sensor-fault)שורת Fault אדומה ב-/device; StateBadge → danger
12שרידות ניתוק חשמללנתק USB באמצע סשן ולחברעולה עם "Resume session?"; boot מציג את סיבת האיפוס
13העברת דאטה מאומתת בזהותcurl ל-/ingest/config בלי header401; עם ה-header ⇒ JSON מלא
14שתי ליבות — המסך שורד עומס רשתלנתק Wi-Fi באמצע סשןהמסך/מגע ממשיכים חלק; ספירת הסשן מדויקת
15שני התקנים על באס I2C אחדself-test ב-bootסריקת I2C מציגה 0x38 + 0x29

הפקודה להדגמת טענה 13 (אימות):

# ללא header ⇒ 401
curl -s -o /dev/null -w "%{http_code}\n" \
  "$APP_BASE_URL/ingest/config?deviceId=mindbox-sim-01"

# עם header ⇒ JSON מלא (downlink)
curl -H "x-device-secret: $DEVICE_INGEST_SECRET" \
  "$APP_BASE_URL/ingest/config?deviceId=mindbox-sim-01"

12.3 Run-of-show — דקה אחר דקה

דקותשלבמה עושים ומה אומרים
0–5הסיפור והארכיטקטורההבעיה (פוקוס, לא זמן) → מה MindBox → תמונת-העל (פרק 1): מכשיר ↔ ענן ↔ אתר. להחזיק את הלוח ביד ולהצביע על המסך, המיקרופון, ה-ToF, האנקודר.
5–9הדלקה + self-test חיהדלקה מול הקהל: boot breadcrumbs + סיבת איפוס על המסך; ב-Serial — סריקת I2C (0x38+0x29), PSRAM, render=sprite-internal, heap. מוכיח טענות 15 + מפת החומרה.
9–14"החיישנים חיים" — Serial mיד (מרחק) · מחיאת כף (רעש/pp) · כיסוי (lux + עמעום מסך) · נשיפה (טמפ') — הכול בשורה חיה אחת. מוכיח טענות 2–5.
14–19סשן חי עם הפרעותהתחלת סשן; רעש מכוון ⇒ אייקון + התראה קולית; התרחקות ⇒ Away; בסיום — סיכום על המכשיר. מוכיח 3, 6.
19–23הדאטה בענן/session/$id — גרפי הדקה-בדקה של הסשן שהרגע נגמר; /device — "Room right now" חי. מוכיח 1, 6.
23–26שליטה דו-כיוונית"Ring my device" (Queued→Sent→Done); החלפת theme; הוספת אירוע ליומן ⇒ מופיע על המכשיר. מוכיח 7, 8.
26–30עומק הנדסי + חוסן2 ליבות (פרק 4), למה המסך לא קורס (פרק 5), שיתוף IO21 (פרק 7), ותיקון ה-pbuf_free (פרק 6). לסיים בניתוק חשמל חי באמצע סשן ⇒ "Resume". מוכיח 9, 12, 14. להשאיר דקה ל-Q&A.

12.4 גיבוי בלי חומרה

אם החומרה נופלת (brownout, רשת) — כל נתיב שרת ניתן להדגמה עם הסימולטור: bun run simulate לזרם טלמטריה חי אל /device; -- --sensor-fault / --low-battery / --offline-then-sync לתרחישי קצה; -- --config להדפסת ה-downlink; ומחזור פקודות מלא (--send-command ⇒ Queued ⇒ --config ⇒ Sent ⇒ --ack ⇒ Done). לחלופין, עמוד /simulator באתר לדמו בלי טרמינל.

נספח D — מילון מונחים

FLE — Focus Load Estimate, אומדן עומס פוקוס (0–100). · ToF — Time-of-Flight, חיישן מרחק לייזר. · ingest — נתיבי ה-API שהמכשיר כותב אליהם. · downlink — הקונפיג שהשרת מחזיר למכשיר. · pbuf — packet buffer של מחסנית ה-רשת lwIP. · sprite — באפר תמונה מחוץ-למסך שמורכב ואז מוטבע בבת-אחת. · NVS — Non-Volatile Storage (הגדרות/checkpoint). · LittleFS — מערכת קבצים על ה-flash הפנימי (תור ה-offline).

שורה תחתונה למנחה: כל טענה במסמך — מפת הפינים, שיתוף IO21, שתי הליבות, אי-קריסת המסך, מסע הנתונים לענן — ניתנת להוכחה חיה תוך שניות, דרך Serial, מסך ה-Diag, או האתר. זה בדיוק מה שהתבקש: מערכת שבה לכל טענה יש דרך להראות ולוודא אותה.
