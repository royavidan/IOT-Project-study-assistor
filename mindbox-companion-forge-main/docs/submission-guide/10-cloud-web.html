10. התקן ↔ ענן ↔ אתר

כאן נסגר המעגל: המכשיר מדבר עם השרת דרך חוזה ingest פשוט (HTTP + secret משותף), השרת כותב ל-Supabase, והאתר מציג הכול כמעט בזמן אמת. אלה נקודות ההוכחה החזקות ביותר לדמו — כי הן נראות על מסך גדול, לא רק ב-Serial.

10.1 חוזה ה-ingest

נקודת הכניסה src/server.ts מפרידה תעבורה לפני ה-router: כל /ingest/* הולך ל-ingest.server.ts. האימות: header x-device-secret בהשוואת זמן-קבוע מול DEVICE_INGEST_SECRET; חסר/שגוי ⇒ 401. הכתיבות רצות ב-service-role client (עוקף RLS), אך הבעלות נבדקת מחדש לכל פעולה רגישה.

10.2 המסכים החיים באתר (נקודות ההוכחה)

הבהרה טכנית חשובה להצגה: אין ב-אתר Supabase realtime/websockets. כל ה"חי" הוא polling של react-query (refetchInterval). זה למעשה קל יותר להסביר ולהדגים ביושר — "האתר שואל את השרת כל X שניות".
המסךקצב רענוןמה זה מוכיח
/device — נקודת Online, סוללה, Wi-Fi, "Room right now" (טמפ'/לחות/אור/רעש), תקינות חיישניםכל 10 שניות (+ tick שעון 15s)טלמטריה מהמכשיר ⇒ שינוי גלוי על המסך תוך ≤10s. ההוכחה החזקה ביותר.
סף Online/Offline90s (3×30s)כיבוי המכשיר ⇒ תוך 90s הנקודה אפורה + "Last seen"
כרטיס שליטה מרחוק (Start/End/Ring/Message) + צ'יפים Queued→Sent→Doneכל 5 שניותנתיב אתר→מכשיר: פקודה עוברת Queued→Sent (המכשיר משך config)→Done (אישר)
Dashboard "Today" (דקות פוקוס, סשנים, סטריק, מצב מכשיר)חלק המכשיר כל 10sסשן חדש מופיע בסיכומי היום
/session/$id — גרפי FLE + דגימות סביבהבטעינהנתוני החיישנים דקה-בדקה שנחתו זה עתה

מקור: src/routes/device.tsx · src/features/device/freshness.ts · lib/queries/sessions.ts.

10.3 הסימולטור — גיבוי לדמו בלי חומרה

שני סימולטורים, שכל אחד מוכיח את החוזה בלי מכשיר פיזי:

  • CLI — bun run simulate (דורש dev server רץ). זורע מכשיר, שולח ~30 יום סשנים (idempotent), ומזרים טלמטריה כל 3s. תרחישים: --offline-then-sync, --low-battery, --sensor-fault, --no-env; ופקודות: --config (מדפיס את ה-downlink בדיוק כמו שהמכשיר רואה), --send-command, --ack, --homework. scripts/simulator.ts
  • עמוד /simulator באתר — GUI ללחיצה: רישום סשן בודד או דחיפת snapshot טלמטריה. אידאלי לדמו בלי טרמינל על המסך.
הוכחת מקצה-לקצה במשפט אחד: המכשיר (או bun run simulate) שולח JSON מאומת-secret ל-/ingest/telemetry ⇒ שורה נוחתת ב-device_status ⇒ ה-polling של react-query (כל 10s) מצייר מחדש את נקודת ה-Online, הסוללה ותנאי החדר — והכיוון ההפוך מוכח ע"י הוצאת פקודה מהאתר וצפייה ב-Queued→Sent→Done. לפני הדמו: ודאו שה-DEVICE_INGEST_SECRET ומפתחות Supabase בסביבה שאליה המכשיר מדבר תואמים למה שהמכשיר צרוב איתו — אחרת המכשיר יקבל 401.
