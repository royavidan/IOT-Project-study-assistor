10. נספחים

10.1 פקודות קונסולת ה-Serial ‏(115200)

פקודה מה היא עושה
m מוניטור 1Hz: מצב, טיימר, נוכחות+מרחק, רעש, אור, טמפ', ‏ToF, ‏WiFi, כפתור, תקלות, תורים
d אותו dump — חד-פעמי
a ‏Audio probe: ‏ACK של הקודק + ‏min/max/DC/AC-RMS גולמיים מהמיקרופון
t / k בדיקת מגע חיה (crosshair) / כיול מגע מחדש
b בדיקת כפתור חיה ‎8 שניות (IO21)
c כיול חיישנים: ‏c מציג; ‏c noise|db|light|lightvar|temp <v> מכוון; ‏c reset מאפס
q מצב תור ההעלאות (ממתינים / הוותיק ביותר / הושלכו)
w הגדרת WiFi / כתובת שרת / secret מה-Serial
h עזרה

בנוסף: ‏selfTest מלא רץ בכל boot ומדפיס — גרסה, סיבת איפוס, זיכרון/PSRAM, סריקת I2C, מרחק ToF, בדיקת מיקרופון, אור, טמפ', ‏WiFi ורשימת הפקודות.

10.2 דגלי הסימולטור (bun run simulate -- ...)

דגל מה מדגים
(ללא דגל) זריעת מכשיר + ‏~30 יום של סשנים + טלמטריה רציפה
--config מדפיס את ה-downlink המלא מפוענח — בדיוק מה שהמכשיר רואה (לו"ז, שבוע, theme, פקודה ממתינה...)
--send-command=<type>[:<arg>][:<text>] / --ack=<id> מחזור פקודה מלא מול הסטטוסים באתר
--homework=<uuid>:<pct> עדכון מטלה "מהמכשיר"
--offline-then-sync צבירת סשנים ואז סנכרון בבת אחת (תרחיש חזרת-רשת)
--low-battery / --sensor-fault ‏StateBadge אזהרה/תקלה + באנר סוללה באתר
--no-env טלמטריה בלי שדות סביבה — הוכחת תאימות-לאחור
--user= / --device= / --ticks= / --interval= / --seed-only / --no-sessions שליטה בזהות ובקצב; ‏bun run cleanup מנקה

10.3 שדות ה-Downlink — רפרנס מלא (‏GET /ingest/config)

שדה טיפוס/טווח תפקיד
paired bool האם המכשיר משויך לחשבון
showTimer, hapticsEnabled, adaptiveCoaching, nudgesEnabled bool הגדרות ליבה
quietStartMin / quietEndMin 0–1439 / 65535 שעות שקט (דקות מחצות; ‏65535=כבוי)
dailyGoalMin, todayFocusSec int יעד יומי + הפוקוס שנצבר היום (לפי היום המקומי)
ownerDisplayName, ownerEmail str ≤19/31B ברכת בעלים על המסך (מחוטא)
tzOffsetMin int אזור זמן המשתמש — כל חישובי "היום" מקומיים
agendaStr "start|end|kind|title;…" ≤12 לו"ז היום (מסך Today + התחלה אוטומטית)
weekStr "day|start|end|kind|title;…" ≤36, ≤10/יום ימים ‎+1..+6‎ לדפדוף
soundEnabled, soundLevel, chimeMask, autoStartEnabled bool / 0–2 / bits / bool סאונד בבעלות האתר; ‏mask: ‏0=לייפסייקל ‏1=סיום ‏2=מתוזמן ‏3=התראות
themeId 0–4 ערכת צבעים (טבלת presets זהה בקושחה ובאתר)
focusMin, breakMin, timingRev 5–120 / 1–60 / epoch זמני פומודורו; מאומצים פעם אחת לכל revision
examMode, nextExamDays, nextExamTitle bool / −1..365 / str ≤23B ‏DND במבחן (ידני או אוטומטי ביום מבחן) + באדג' ספירה
streakDays, weekFocusMin int סטריק ודקות השבוע למסך הסטטיסטיקה
hwStr "uuid|title|pct;…" ≤3 מטלות למסך העדכון המהיר
cmdId, cmdType, cmdArg, cmdText int / 1..6 / int / str ≤40B פקודה מרחוק אחת (‏1=start ‏4=end ‏5=ring ‏6=message)

כללי חיטוי לכל מחרוזת: הסרת ‏" \ | ; ותווי בקרה + קיטום לפי בתים של UTF-8 (מודול משותף device-string.ts + בדיקות יחידה) — כי הפרסר בקושחה מינימלי בכוונה.
