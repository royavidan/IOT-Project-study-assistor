7. צד האתר: איך כל נתון נקלט, נשמר ומוצג

7.1 שני נתיבי דאטה, נקודת כניסה אחת

src/server.ts הוא ה-fetch entry: בקשות /ingest/* (מהמכשיר) ו-/jobs/* (cron) מפוצלות לפני ראוטר האפליקציה — מאומתות ב-shared secret וכותבות דרך service-role (עוקף RLS, עם בדיקת בעלות מחדש בקוד). כל השאר עובר דרך TanStack Start: סשן משתמש, Row-Level Security (כל משתמש רואה רק את השורות שלו), ו-CSRF guard על כל בקשה שאינה GET.

7.4 סימולטור — הדגמת הצד השרתי בלי חומרה

scripts/simulator.ts מדבר את אותו פרוטוקול HTTP בדיוק כמו הקושחה (אותם routes, אותו secret) — כלי הבדיקה המרכזי של האינטגרציה וגם רשת ביטחון לדמו. הרשימה המלאה בנספח; העיקריים: --config (מציג את ה-downlink המפוענח כפי שהמכשיר רואה), --send-command / --ack (מדמים את מחזור הפקודות), --sensor-fault / --low-battery (מדגימים את נתיב ההתראות), --no-env (מוכיח תאימות-לאחור של הסכמה).
