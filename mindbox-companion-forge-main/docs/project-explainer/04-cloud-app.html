4Cloud, app & the 16 features

The box talks to a server over a few small, secured messages; the website turns that into live dashboards, remote control, and everything the 16 user stories promise.

In one line: The box is like a phone texting short, secret-signed updates to a server; the website reads them and can text back settings and commands.

4.1 How the box talks to the cloud

Every message carries a shared secret header — a wrong or missing secret is rejected (401).

MessageDirectionWhat it carries
sessionsbox → servera finished session (+ minute-by-minute data)
telemetrybox → servera 30-second heartbeat: state, battery, Wi-Fi, room conditions
configserver → boxevery 60s: the box's settings + any remote command
pairing / unpairbox → serverclaiming / releasing the box
homeworkbox → serverhomework progress bumps
Honest detail The website's "live" updates are polling (it asks the server every few seconds), not push — simpler, and easy to demonstrate.
